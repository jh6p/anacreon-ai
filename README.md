# anacreon-ai

A Go program that edits the save file to provide metadata to the player or play as another player.

## Building

Requires [Go 1.24](https://go.dev/dl/) or later.

```bash
go build -o anacreon-ai
```

This produces the `anacreon-ai` binary in the current directory.

## Running

```bash
go run .
```

Or run the compiled binary directly after building.
